## SimCSE: Simple Contrastive Learning of Sentence Embeddings

- **Authors / venue:** Tianyu Gao, Xingcheng Yao, Danqi Chen; EMNLP 2021, verified by [ACL proceedings](https://aclanthology.org/2021.emnlp-main.552/).
- **Target:** Table 5, unsupervised BERT-base average STS Spearman correlation **76.25%**, across the paper's STS evaluations. [Primary paper](https://arxiv.org/html/2104.08821v2); [proceedings PDF](https://aclanthology.org/2021.emnlp-main.552.pdf).
- **Official code / license:** [princeton-nlp/SimCSE](https://github.com/princeton-nlp/SimCSE), [MIT](https://github.com/princeton-nlp/SimCSE/blob/main/LICENSE).
- **Compute estimate:** Local mixed-precision BERT-base training is plausible with short sequences; full paper batch size must pass a memory check. Gradient accumulation does not recreate a larger contrastive negative pool. If the original batch cannot fit, explicitly record a reproduction deviation, or use available cloud GPU access after the human supplies it. Plan independent training seeds and report seed uncertainty; no invented time estimate.
- **Fit:** PyTorch, contrastive embeddings, retrieval, and validation-based fine-tuning. Strongest connection to CVE-RAG.
- **Proposed additional ablation:** Compare identifier-preserving versus identifier-normalizing text processing on an alias-cluster-separated vulnerability retrieval validation/test protocol. This examines whether exact identifiers carry useful domain information. This is an extension evaluation, separate from the original STS headline reproduction; fit the preprocessing choice on validation only.
- **Novelty status:** No claim that this domain ablation was absent from the paper until the full appendix and official code have been checked. Dropout, pooling, temperature, and hard-negative ablations are already studied by the authors and are not proposed as new.
- **Risks:** Old dependency stack versus current local Python; evaluation conventions, pooler selection, and checkpoint selection can alter results. Wiki training text and STS data availability/terms need a pinned audit. Smaller batches change the objective. Domain-transfer negatives need strict alias-cluster leakage assertions.

## Simple Baselines for Image Restoration (NAFNet)

- **Authors / venue:** Liangyu Chen, Xiaojie Chu, Xiangyu Zhang, Jian Sun; ECCV 2022, verified by [official ECVA proceedings](https://www.ecva.net/papers/eccv_2022/papers_ECCV/html/3043_ECCV_2022_paper.php).
- **Target:** Table 6, NAFNet RGB denoising on SIDD, **40.30 dB PSNR**. [Primary paper, Table 6](https://arxiv.org/html/2204.04676v3).
- **Official code / license:** [megvii-research/NAFNet](https://github.com/megvii-research/NAFNet), [Apache 2.0](https://github.com/megvii-research/NAFNet/blob/main/LICENSE).
- **Compute estimate:** Pretrained-checkpoint inference on benchmark patches should fit the local card. Full original training is not proposed; it requires substantially more compute. A smaller patch-training extension may be feasible after a memory check, with deviations reported explicitly. Evaluation-only reproduction must never be called a training reproduction.
- **Fit:** Computer Vision, image restoration, PyTorch, perceptual versus pixel metrics; complements SRGAN while remaining separate solo work.
- **Proposed additional ablation:** Validation-selected robustness to a fixed input quantization policy, followed by untouched held-out evaluation. This tests deployment sensitivity rather than claiming better denoising. Check the paper, supplement, and associated local-conversion work for overlap before finalizing.
- **Risks:** SIDD benchmark versus validation split must be distinguished. [Official SIDD access](https://abdokamel.github.io/sidd/) and terms need auditing. Public checkpoint metrics and paper benchmark metrics may use different splits. Original training cannot be reproduced locally as proposed. Repeating deterministic checkpoint inference with different RNG seeds does not yield independent training-seed evidence.

## Depth Anything V2

- **Authors / venue:** Lihe Yang, Bingyi Kang, Zilong Huang, Zhen Zhao, Xiaogang Xu, Jiashi Feng, Hengshuang Zhao; NeurIPS 2024, verified by [official proceedings](https://proceedings.neurips.cc/paper_files/paper/2024/hash/26cfdcd8fe6fd75cc53e92963a656c58-Abstract-Conference.html).
- **Target:** Table 3, ViT-S relative-depth pairwise accuracy on DA-2K, **95.3%**. [Primary paper, Table 3](https://arxiv.org/html/2406.09414v2).
- **Official code / license:** [DepthAnything/Depth-Anything-V2](https://github.com/DepthAnything/Depth-Anything-V2). Official [license policy](https://github.com/DepthAnything/Depth-Anything-V2#license) gives the Small checkpoint Apache 2.0; larger checkpoints have different, noncommercial terms. Restrict this proposal to Small.
- **Compute estimate:** Small-model checkpoint inference should fit the local card. Original pretraining is beyond the local budget and will not be claimed. Fine-tuning is conditional on an appropriately licensed separate train/validation dataset and a memory check.
- **Fit:** Computer Vision, transformer features, deployment, domain-slice error analysis; adds a task distinct from image restoration.
- **Proposed additional ablation:** A validation-chosen input precision/quantization policy, with pairwise-depth stability and error slices measured on the held-out benchmark. Verify absence from the full paper and supplement before treating it as a new ablation.
- **Risks:** [Official DA-2K instructions](https://github.com/DepthAnything/Depth-Anything-V2/blob/main/DA-2K.md) link the downloadable benchmark, but image access/terms still need a source audit. Image-level bootstrap must respect multiple point pairs per image. Checkpoint inference is deterministic; it cannot substitute for independent training seeds. Original pretraining/data mixture is not reproducible within the local budget.
